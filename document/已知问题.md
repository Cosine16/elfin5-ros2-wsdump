## 真机实测（2026-08-21，接真机验证记录）

### 18. DDS 跨用户：root 节点的 SHM 段/信号量挡住普通用户（2026-08-28 根因修正，已解决）
- **之前的结论（"ROS_LOCALHOST_ONLY=1 即解决"）是错的**：实机上 root 跑驱动、fit 跑 CLI/GUI 时，fit 侧 `ros2 service call` 卡 waiting、`node list` 为空，实测从未真正互通。
- **根因**：本机 lo 上完全没有 UDP 组播 PDP 流量（tcpdump 实测 0 包），Fast DDS 2.0 的同机发现实际走 `/dev/shm/fastrtps_*` 段文件扫描 + 段内投递。root 创建的段为 0644、`sem.fastrtps_port*_mutex` 信号量也非 world-rw，fit 打开报 EACCES（strace 实测），发现与数据双静默失败。chmod 放开权限后仍不通，确认该 SHM 通道本身不支持跨用户。
- **否决的方案**：给 ros2_control_node 打 file capabilities（setcap cap_net_raw）——带 caps 的进程被 glibc 置于 secure-execution 模式，**LD_LIBRARY_PATH 从环境变量中被抹掉**，而 Foxy 的 `rcpputils::find_library_path` 恰恰用 getenv("LD_LIBRARY_PATH") 找 rmw 库（rmw_implementation functions.cpp:73 报错），此路不通。
- **最终方案（已验证）**：硬件终端改用 `sudo capsh --keep=1 --user=fit --inh=cap_net_raw,cap_sys_nice --addamb=...` 启动——进程是 fit 身份 + ambient capabilities，exec 普通二进制不触发 secure 模式，LD_LIBRARY_PATH 完好；实测 raw socket 可开绑 enp2s0、fit 全网 DDS 收发正常。已固化进 `start_real.py`（默认行为；`--sudo` 回退旧全 root 模式）。
- **善后**：全部停掉后可清理残留 `/dev/shm/fastrtps_*` 与 `/dev/shm/sem.fastrtps_*`（需 root）。残留段会导致新进程发现异常、ros2 daemon 100% CPU 空转。
- **排查提示**：foxy 的 ros2 CLI 走 daemon 缓存，图查询诡异（如空 node list）先 `ros2 daemon stop`，并用 `--no-daemon` 交叉验证，勿当真相。

### 22. 使能后 100ms 出现一拍"角度回绕"坏命令，机械臂猛冲触发 fault（2026-08-28 实踩，待修）
- **现象**：面板 Servo On 使能后约 100ms，机械臂巨响猛冲，6 轴全部 fault（错误码 0x0080）掉使能；第二次使能原样复现。
- **抓包证据**（`桌面/capture/260828-1835 上电后发出巨响.pcapng`，解析脚本 `/tmp/ecat_analyze.py`）：使能序列本身干净（目标=实际，偏差≤2 计数）；使能后恰好一个 50Hz 控制周期（19.1ms）内，六轴目标位置同帧突变为固定错误向量，电机力矩饱和 ±10000‰ 冲击后全 fault。错误向量换算回弧度 ≈ [J1=2π, J2=0, J3=π/2, J4=−2π, J5=π/2, J6=0]，模 2π 恰等于当前姿态——典型的角度被错误归一化到 [0,2π)。
- **机制**：`elfin_hardware_interface.cpp:318 write()` 在未使能（`inPosBasedMode()=false`）时每拍把 cmd 对齐实际位置，掩盖了 JTC 缓冲里的陈旧/回绕设定点；使能瞬间守卫放开，输出一帧坏命令；fault 掉使能后守卫恢复，所以只坏一拍。
- **嫌疑源**：使能前某条经 MoveIt 归一化的轨迹（含 ±2π 表示）残留在 JTC 的保持设定点中。待查：使能时刻前后的 controller_manager switch / action goal 记录（root 日志 `/root/.ros/log/ros2_control_node_*.log`）。
- **临时规避**：使能前不做任何规划/点动；必要时使能前先 deactivate/activate `elfin_arm_controller` 让 JTC 重新以当前位置 hold。
- **根治方向**：`write()` 输出前把 `position_cmd` 相对当前 `position` 做 ±π 最短路径回绕（物理等价，免疫 2π 表示差异）。

### 20. GUI 轮询 IO 引发 slave5 SDO 报错 + catch-all 吞异常（已定位，未修）
