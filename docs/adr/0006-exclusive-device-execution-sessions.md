# ADR 0006：以设备级独占执行会话仲裁运动控制权

- 状态：已接受
- 日期：2026-11-14

## 背景

同一设备可能同时存在直接技能、Nav2、MoveIt、SmolVLA 闭环和人工诊断入口。若只依赖 Agent 提示词避免并发调用，仍可能出现多个运动发布者、任务状态不一致和停止语义不清。现有仓库文档也明确记录了多控制源不能并行抢控制权的要求。

## 决策

在 RoboNeuron 边界为每款设备建立独占执行会话：

- 任务取得设备会话后才能启动运动能力。
- 直接技能与 VLA 闭环不能同时持有同一设备的会话。
- 停止操作可以抢占并撤销活动会话；完成停止和状态清理后才释放给下一任务。
- 三款设备的会话相互独立，跨设备任务按明确顺序取得和释放，不假设一个全局会话适合所有设备。
- 云端断链时活动会话是续跑还是停止，由独立的断链策略决定，不在本会话机制中隐含固定行为。

## 后果

- 控制权、任务生命周期和停止行为有统一运行时依据，不再只是提示词约定。
- 每个设备适配器需要接入会话获取、释放、抢占和状态清理。
- 长运行 VLA 与短时直接工具必须遵循同一会话语义，现有独立 bridge 不得绕过会话并行发轨迹。
- 跨设备技能需要处理部分成功、会话释放和人工接管，复杂度高于单设备任务。

## 备选方案

- 任务技能自行加锁：改动较少，但不同技能容易遗漏或产生不一致实现。
- VLA 始终优先：策略简单，但停止和任务切换语义不清。
- 仅依赖 Agent 提示词：没有运行时保证，不能作为真机安全边界。
