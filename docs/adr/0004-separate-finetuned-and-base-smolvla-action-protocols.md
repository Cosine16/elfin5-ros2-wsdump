# ADR 0004：显式分离 Elfin5 微调与 base 演示动作协议

- 状态：已接受
- 日期：2026-11-14

## 背景

预训练 `lerobot/smolvla_base` 来自不同机器人 embodiment，其六维输出不具备 Elfin5 绝对关节位置语义。仓库现有链路演示采用相邻动作差分积分、单步钳制和关节限位；未来 Elfin5 微调模型则需要与自有数据集统计一致的绝对关节位置目标。共用同一个未声明语义的六维协议会使配置切换变成危险的动作语义切换。

## 决策

使用两个显式隔离的协议：

1. Elfin5 微调 checkpoint 使用微调关节位置协议，输出经该 checkpoint 对应统计反归一化后表示六关节绝对位置。
2. 预训练 base 仅使用独立命名的相对增量演示协议，沿用受限的安全映射进行链路验证，不用于 Elfin5 真机抓放任务能力验收。

协议选择必须与模型、数据集统计和运行配置绑定，不得静默切换。关节顺序、限位、限速、状态新鲜度和停止行为在接口实现与验收中显式检查。

## 后果

- base 链路演示与未来微调部署可以共存，且不会因维度相同而误用动作。
- 微调数据集、归一化统计、checkpoint 与部署配置必须作为同一个可追溯单元管理。
- 需要维护两套协议及其测试，增加少量实现与文档成本。
- base 相对增量演示产生的运动不能作为任务成功率或可靠抓放能力证据。

## 备选方案

- 全部使用相对关节增量：协议较少，但需要持续处理参考状态、积分漂移和训练一致性。
- 全部使用绝对关节位置：部署语义直接，但未经 Elfin5 微调的 base 不能安全地用于真机任务。
- 推迟定义数值语义：短期实现自由，但无法冻结数据契约和真机验收边界。
