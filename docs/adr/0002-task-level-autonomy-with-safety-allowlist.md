# ADR 0002：真机采用任务级自主与安全白名单

- 状态：已接受
- 日期：2026-11-14

## 背景

项目中的 Agent 定位为自主机器人操作员，而不是逐步等待用户点击确认的工具面板。与此同时，Elfin5 工作站和 leapROS 小车都涉及真实运动，云端模型输出、网络异常或错误技能编排不能直接转化为不受约束的真机动作。

## 决策

采用任务级自主：用户下达一次高层任务后，Agent 可以自主选择并编排技能，不要求逐步确认每次运动。真机自主调用仅限经过审查的安全白名单，运动受速度、工作范围、执行时长、停止和人工接管约束；完全不受限的自主执行不在首期范围内。

具体数值限制和各技能准入条件在设备接口盘点与安全验证后分别确定，不在本决策中预设。

## 后果

- 演示能够体现 Agent 的任务级规划与工具编排，而非人工逐步遥控。
- 每个真机技能都需要明确准入条件、执行边界、停止行为和验证证据。
- 白名单会限制 Agent 可自由生成的动作范围，部分开放式任务可能被拒绝或降级。
- 仿真与真机可以使用不同权限配置，真机权限不能由仿真成功自动推定。

## 备选方案

- 每次运动均由人工确认：操作约束更强，但削弱自主操作员的参赛主线。
- 完全自主执行：减少人工介入，但真机安全与现场可重复性风险不可接受。
- 首期只做仿真自主：验证较容易，但无法满足三平台真机接入演示目标。
