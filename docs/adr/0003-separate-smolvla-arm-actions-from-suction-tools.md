# ADR 0003：分离 SmolVLA 六关节动作与双吸盘工具

- 状态：已接受
- 日期：2026-11-14

## 背景

Elfin5 有六个机械臂关节，末端为两个真空吸盘。RoboNeuron 原有 VLA 契约主要围绕七维末端位姿增量或 Cartesian 速度及一个夹爪开合量，现有 SmolVLA base 的六维输出又来自不同机器人。直接把六维输出解释为 Elfin5 绝对关节位置、七维 Cartesian 动作或夹爪动作都会造成语义错误。

项目需要在固定工位抓放中引入 SmolVLA，同时保留明确、可审查的吸附与释放安全边界。

## 决策

首期让 SmolVLA 只输出对应 Elfin5 六个关节的动作。吸附与释放由独立、显式、纳入安全白名单的工具控制，不加入 VLA 动作向量，也不映射为 `gripper_open_fraction`。

动作向量的绝对或相对编码、归一化、执行频率和 base 模型专用演示映射必须在具体协议中明确区分，不得仅因维度相同而复用。两个吸盘是否共用气路、具有何种反馈，由设备盘点决定，不影响本次“吸盘不进入 VLA 动作向量”的边界。

## 后果

- 机械臂策略与真空执行器可以分别验证，吸盘控制能够独立纳入准入和停止逻辑。
- 抓放不是完全端到端 VLA 行为，吸取与释放时机由 Agent 或任务技能编排。
- 需要为 Elfin5 定义显式关节动作协议，不能原样使用 RoboNeuron 的七维 Cartesian 协议。
- 数据采集只需为 VLA 记录六关节动作标签；吸盘事件仍应作为任务执行证据记录，但不作为本策略的额外动作维度。
- 若未来改为端到端学习吸附时机，需要新的数据标签、动作协议和安全验证，不属于配置级切换。

## 备选方案

- 七维关节加同步吸盘：可以学习吸附时机，但需要对应标签与协议扩展。
- 八维关节加两路独立吸盘：表达能力更强，但数据与安全复杂度更高。
- Cartesian 动作加独立吸盘：可复用 RoboNeuron IK 路径，但需要重新统一训练数据和 Cartesian 动作语义。
